# Supplementary Material

Companion code and data for:

> N. H. Ansari, N. Kafi Khan, S. Wasi, and M. S. Siddiqui, "The Human Factor: A
> Behavior- and Workload-Aware Risk-Scoring Agent for IT Administrators in
> Multiagent Cyber Risk Assessment," submitted to *IEEE Access*.

This package matches the final paper: **7 figures, 8 tables**. All randomness
is seeded; a fresh run reproduces every shipped file byte for byte. No real
organizational or personal data is used — all data are generated by the
simulation of Section VII.

## Reproduce

    pip install -r requirements.txt
    cd code
    python reproduce_all.py

Runs all 7 pipeline steps in order and regenerates every file in `data/`
(19 CSV, 3 JSON) and Figs. 3–7 in `figures/`. Figs. 1–2 are conceptual
architecture/workflow diagrams with no underlying data to regenerate from —
they are included as final images only. The code produces exactly the 7
figures used in the paper and no others: the analyses behind VIII-G and
VIII-J's text-only numbers (threshold/weight sweep, data-quality sensitivity)
write their CSVs as usual but are not plotted, since no chart for them
appears in the paper.

## A note on the rest of `data/`

Several files back numbers that are stated in the running text but are not
displayed in a table or figure (e.g., the decision-analytic cost figures of
VIII-E, the calibration Brier scores of VIII-F, the threshold/weight
sensitivity of VIII-G, the ablation results of VIII-H, and the data-quality
sensitivity of VIII-J). These are included because the paper's reproducibility
claim covers every reported number, not only the ones shown in a table or
figure:

## Scope

The code validates the scoring and attribution mechanism. It does not execute
the eight-node LangGraph workflow against live connectors and makes no LLM
call, since every decision-relevant quantity is deterministic and the language
model only writes rationale text (Section VI, Scoring Authority).
